# Life Dashboard

這是我自己在用的個人財務與生活儀表板。一開始只是想記帳，後來把資產、股票、習慣、待辦、心情、行事曆、想買的東西全塞進同一頁，就變成現在這樣了。

整套東西沒有自己的伺服器、也沒有正規資料庫。前端就是一支 `index.html`（HTML、CSS、JS 全寫在同一個檔案裡），資料全部放在一份 Google Sheet，中間靠一支 Google Apps Script（`backend.gs`）當 API。會這樣搞純粹是因為免費、不用養機器，而且資料本身就是一張試算表——哪天程式壞了，我至少還能直接打開 Google Sheet 看跟改。

## 由三塊組成

- **前端 `index.html`**：放在 GitHub Pages。畫面分四頁（底部分頁切換）：首頁、記帳、資產、更多。圖表用 Chart.js（CDN 載入）。版面是響應式多欄，桌機並排、手機收成單欄。
- **後端 `backend.gs`**：部署成 Google Apps Script 的 Web App。`doGet` 讀某分頁回 JSON；`doPost` 負責新增、刪除、更新、批次寫入。寫入全程用 `LockService` 上鎖，避免兩個請求同時寫進去打架。另外還放了幾個給試算表用的自訂函數，以及幾個排程跑的背景工作。
- **資料庫＝Google Sheet**：每個功能對應一個分頁（tab），第一列是欄位名稱，下面就是資料。

前端和後端只靠一條 GAS 網址溝通。這條網址和登入密碼存在瀏覽器 localStorage，第一次開網頁時會問你。

## 四個頁面有什麼

**首頁**
- 行事曆：把待辦截止日、倒數事件、固定支出扣款日、台灣國定假日都標在對應那天；今天藍圈、週末與假日紅字；點某天列出當天所有安排，可前後切換月份。
- 時間倒數：年度進度條 + 自訂倒數事件（一次性 / 每年重複）。
- 今天打卡：英文 / 運動 / 讀書 / 睡覺，下面一條把「有沒有打卡」換算成複利的能力成長曲線。
- 待辦事項：任務 + 截止日 + 優先序，依「截止日近、優先高」排序，逾期紅字、可勾完成、可刪除。
- 心情日記：每天選心情（1–5）+ 一句話，顯示最近幾篇與一條心情曲線。

**記帳**
- 生活可用餘額、本月已花 / 預算 / 儲蓄率。
- 日常記帳：快速帶入會依你最常記的項目自動排序、帶上次金額；每筆有唯一 ID，可直接在列表編輯或刪除。
- 轉帳 / 領錢：一次原子寫入兩筆（轉出 + 轉入）。
- 本月 vs 上月支出比較（圖 + 表）。
- 最近紀錄：可搜尋、可依類別 / 帳戶篩選、可載入更多。

**資產**
- 總資產淨值、今日總損益、第一桶金目標進度與預估達標時間。
- 成本、損益、ROI、組合 Beta。
- 資產趨勢（總資產 + 股票 / 現金 / 黃金 分類合計線，靠快照累積）。
- 配置比例圓餅（前 8 大 + 其他）。
- 持股明細、每月收入（主動 / 被動）。
- 股票交易：自動算手續費與證交稅，買 / 賣一次原子寫入兩筆；另有進階手動記錄（現金調整、加密貨幣等）。

**更多**
- 深色模式切換（自動跟時間 / 淺色 / 深色）。
- 固定支出：列出每月固定開銷，到扣款日由排程自動記帳。
- 帳戶餘額對帳、夢想購物車（自動判斷餘額夠不夠買）、知識書櫃（書 / 影 / 課的評分與心得）。

## 各分頁（資料表）

- `Expenses_DB`（日常記帳）：日期、類別、項目、金額、帳戶、收支、ID
- `Asset_Log`（資產與現金流水帳）：日期、帳戶、資產類別、項目名稱、數量、金額、交易型態
- `Portfolio`（持股現況與即時報價）：項目名稱、持有數量、即時單價、昨日收盤、總市值、個股 Beta、加權 Beta
- `History_Log`（資產快照存檔）：日期、資產名稱、持有單位、現淨值、總成本
- `Habit_Log`（習慣打卡）：日期、英文、運動習慣、讀書習慣、睡覺習慣
- `Events_DB`（倒數事件）：事件名稱、日期、類型（`fixed` 一次性 / `yearly` 每年）
- `Wishlist_DB`（夢想購物車）：日期、項目名稱、預估金額、連結/備註、ID
- `Media_Log`（知識書櫃）：日期、類別、標題、評分、心得
- `Todo_DB`（待辦事項）：任務、截止日、優先、完成、ID
- `Mood_DB`（心情日記）：日期、心情、內容、ID
- `Recurring_DB`（固定支出）：項目、類別、金額、帳戶、扣款日、啟用
- `Settings`（選用，調目標和預算）：項目、數值

後端寫入是「對欄位名稱」而不是「對欄位順序」，所以就算在中間插一欄、調動順序，資料還是會落在正確欄位；連標題不小心多打空白也會自動容錯（前端讀進來會把欄位名前後空白去掉）。記帳和願望清單有 `ID` 欄，刪除 / 編輯靠 ID 精準命中；沒有 ID 的舊資料則退回「日期＋項目＋金額」比對（僅限最近 30 筆）。

## 自動抓價（給試算表用的自訂函數）

寫在 `backend.gs` 裡，直接在 Google Sheet 的儲存格用：

- `=GOLD_NOW()` / `=GOLD_PREV()`：台灣銀行黃金存摺現價 / 前一營業日價（本行買進，新台幣/公克）
- `=STOCK_NOW(代號)` / `=STOCK_PREV(代號)`：台股即時價 / 昨收，給 GOOGLEFINANCE 抓不到的股票用（以 Yahoo Finance 為主、證交所 MIS 備援，自動分辨上市 / 上櫃）
- `=BETA(代號)`：個股對台股加權指數（^TWII）的 Beta，用兩年週報酬算（臨時查單檔用；整欄交給下面的排程）

注意這些是寫在後端 `.gs` 裡的自訂函數，更新後端時別把它們弄不見（之前覆蓋整份檔案時刪掉過 GOLD 函數，黃金那列就變 `#NAME?`）。

## 背景排程與推播（Bark）

`backend.gs` 裡有幾個時間觸發器（執行一次 `setupTriggers` 建立；它會先清掉所有舊觸發器再重建，避免殘留亂報錯）：

- `autoLogRecurring`（每天凌晨）：到扣款日就把 `Recurring_DB` 的固定支出自動記進 `Expenses_DB`，記完 Bark 通知。
- `dailyLogReminder`（每天 22:00）：當天還沒記任何一筆才 Bark 提醒。
- `todoReminder`（每天早上）：推播今天到期 + 逾期的未完成待辦。
- `updateBetas`（每週日）：把 `Portfolio` 的「個股 Beta」整欄重算寫入。

推播用 Bark：到「專案設定 → 指令碼屬性」新增一個屬性 `BARK_KEY`，值是你的 Bark key（多支裝置用逗號分隔）。

> GAS 時間觸發器無法精準到分秒，`atHour(22)` 是「22:00–23:00 內某個時間點」跑，所以實際可能 22:2x 才送，屬正常。

## 目標金額、每月預算

用 `Settings` 分頁調，不必動程式：

| 項目 | 數值 |
| --- | --- |
| 第一桶金目標 | 1500000 |
| 每月預算 | 15000 |

A 欄的字只要「包含」關鍵字就抓得到（含「目標 / 桶金」當目標、含「預算」當月預算）。沒有這個分頁就用內建預設（目標 150 萬、預算 15000）。

## 其他功能

- **PWA**：有 `manifest.json` 和 `service-worker.js`，可「加入主畫面」變成全螢幕 App；service worker 會快取 App 本體與上次抓到的資料，沒網路也能打開看上次的數字（但看到的是快照、不是即時，離線也不能記帳）。
- **深色模式**：自動跟時間（18:00–06:00 變深）/ 固定淺色 / 固定深色，三段循環，記在 localStorage。

## 從零架起來

1. 開一份 Google Sheet，照上面的格式把分頁和欄位建好。
2. 擴充功能 → Apps Script，把 `backend.gs` 整份貼進去、存檔。
3. 部署 → 新增部署 → 類型「網頁應用程式」→ 執行身分設成你自己、誰可以存取選「任何人」→ 部署，複製拿到的網址（結尾是 `/exec`）。
4. 把前端放上 GitHub Pages（這個 repo 本身就是）。
5. （選用）到「指令碼屬性」加 `BARK_KEY`；在編輯器執行一次 `setupTriggers` 建立排程。
6. 開網頁，貼上 GAS 網址、設一組密碼。完成。

## 改版怎麼更新（最容易踩雷）

前端和後端是分開更新的：

- **改前端（`index.html` 等）**：push 到這個 repo，GitHub Pages 過一兩分鐘自動更新，重新整理網頁就生效。
- **改後端（`backend.gs`）**：push 到 GitHub 不會生效。真正在跑的是 GAS 雲端那份，要自己把程式碼貼回 Apps Script，然後「部署 → 管理部署 → 編輯現有那個 → 版本選『新版本』→ 部署」。一定要用「編輯現有」，網址才不會變、前端不用改設定。若改到排程或自訂函數，記得重存檔（必要時重跑 `setupTriggers`）。

## 已知的限制（老實講）

- **登入密碼不是真的資安**。它只擋網頁畫面，真正的鑰匙是那條 GAS 網址，誰知道網址就能直接讀寫整份試算表，後端目前沒做驗證。所以網址別外流；`config.js`（含網址和密碼）用 `.gitignore` 擋掉了，不要上傳。（`index.html` 現在是用 localStorage 問你網址，`config.js` 其實是早期留下的、目前沒在載入，但裡面是機密照樣別上傳。）
- **沒有 ID 的舊紀錄**刪除只比對最近 30 筆、靠「日期＋項目＋金額」湊，太舊的刪不掉、同日同額可能刪錯。新資料都有 ID 就沒這問題。
- **資產交易（Asset_Log）目前不能在 App 裡改 / 刪**，要修正買賣或轉帳得直接去 Google Sheet 改。
- **資產趨勢圖靠手動快照**：資產頁按「快照」才會把當下資產存進 `History_Log` 當一個時間點，沒定期按就沒資料。
- **股價 / 金價是試算表公式**，公式壞掉（例如 `#NAME?`）那格就沒值；前端有防呆，抓不到一律當 0，至少不會把總資產算成 NaN。
- **今日總損益**只算有有效「昨日收盤」的持股；昨收還是佔位 `1` 的那幾檔不列入。

## 檔案

- `index.html` — 前端整包（畫面、樣式、邏輯都在裡面）
- `backend.gs` — GAS 後端（`doGet` / `doPost` + 自訂函數 + 排程），要貼到 Apps Script
- `manifest.json`、`service-worker.js` — PWA 用
- `config.example.js` — 設定檔範本（真正的 `config.js` 不進版控）
